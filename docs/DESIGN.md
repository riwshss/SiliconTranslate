# 絲譯 Silk Translate：視覺與界面規範（Silk & Ink）

> **給 Claude Code：** 修改任何界面（工具欄面板、頁面懸浮條、劃詞卡片、雙語譯文、圖標）前先讀這份文件。
> - 顏色、字體、圓角、動效一律用第 3–6 節的 token，不要在組件裡寫新的顏色值。
> - 第 10 節是實施清單，按順序做；完成後在 `docs/ROADMAP.md` 的決策記錄追加一行。
> - 這份規範和 `docs/ROADMAP.md` 第 3 節「開發原則」衝突時，以開發原則為準。

---

## 1. 設計理念

**名稱：Silk & Ink（絲與墨）**

「絲譯」的意思是：譯文像一縷絲線，把原文和譯文輕輕縫在一起，不撕裂原來的頁面。

- **墨（Ink）：** 深靛藍黑色，用於文字和主要操作。冷靜、可信、像好的排版。
- **紙（Paper）：** 暖白色背景，像宣紙，不是冷灰。
- **絲（Silk）：** 一條細而流暢的金色絲線，是品牌的核心圖形。用於進度、加載、圖標、分隔，**只做裝飾，不承載文字信息**。
- **印（Seal）：** 朱砂紅，只出現在品牌標誌和宣傳物料裡，像落款印章。界面裡幾乎不用。

### 三個關鍵詞

1. **安靜：** 翻譯插件是寄生在別人網站上的，界面要退到後面。少色塊、少陰影、少動畫。
2. **精準：** 細線、對齊、克制的圓角。開發者用戶會注意到不整齊。
3. **東方而現代：** 靠配色和一條絲線表達，不用書法字、水墨畫、祥雲紋這類符號。

- 淺色模式不要用純黑 `#000` 和純灰背景；深色模式不要用純黑背景。

## 4. 字體

擴展不打包網頁字體（零運行時依賴、體積小），全部用系統字體，**按界面語言調整中文字體的順序**。

```css
/* 繁中界面（:lang(zh-TW)、:lang(zh-HK)） */
--font-ui: ui-sans-serif, -apple-system, "Segoe UI Variable Text", "Segoe UI",
  "PingFang TC", "Microsoft JhengHei", "Noto Sans TC", sans-serif;
/* 簡中界面 */
--font-ui: ui-sans-serif, -apple-system, "Segoe UI Variable Text", "Segoe UI",
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif;
/* 代碼 */
--font-mono: ui-monospace, "SF Mono", "JetBrains Mono", Menlo, Consolas, monospace;
```

- 繁中界面優先繁體字形（PingFang TC、微軟正黑體）。否則同一個漢字在繁中界面裡會用到簡中字形，台灣、香港用戶一眼就看得出來。
- 實現上：根據解析後的界面語言，給 `<html>`（面板）或 Shadow DOM 根節點設置 `lang` 屬性，CSS 用 `:lang()` 切換。

### 字號（面板與卡片）

| 名稱 | 大小 / 行高 | 字重 | 用途 |
|---|---|---|---|
| title | 16 / 22 | 650 | 面板標題 |
| body | 13 / 20 | 400 | 正文、選項 |
| label | 12 / 16 | 550 | 分組標題、按鈕 |
| caption | 11.5 / 16 | 400 | 說明、額度 |
| card-text | 14 / 22 | 400 | 劃詞卡片裡的譯文（需要好讀） |

宣傳物料可以用思源宋體（Noto Serif TC）做大標題，和界面的無襯線體形成對比。**界面裡不用襯線體。**

## 5. 形狀、間距、陰影

- **間距：** 4 的倍數（4 / 8 / 12 / 16 / 20）。面板外邊距 14 → 16。
- **圓角：**
  - `--radius-sm: 8px`：小按鈕、輸入框
  - `--radius: 12px`：卡片（現值 14 → 12，更精準）
  - 膠囊形（`999px`）：HUD、徽章
- **邊框：** 優先用 1px `--line` 細線區分層級，少用陰影。
- **陰影：** 只在浮在網頁上方的元素（HUD、劃詞卡片）使用：
  - 淺色：`0 1px 2px rgba(27,34,48,.06), 0 12px 32px -12px rgba(27,34,48,.28)`
  - 深色：`0 1px 2px rgba(0,0,0,.35), 0 16px 40px -14px rgba(0,0,0,.65)`
- **毛玻璃：** HUD 和劃詞卡片保留現有的 `backdrop-filter`，底色換成 `--surface`。

## 6. 動效

| token | 值 | 用途 |
|---|---|---|
| `--ease-silk` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 默認：出現、移動 |
| `--ease-out` | `cubic-bezier(0.3, 0, 0.2, 1)` | 消失 |
| `--dur-fast` | `120ms` | 懸停、按下 |
| `--dur` | `200ms` | 展開、切換 |
| `--dur-slow` | `320ms` | HUD 出現、卡片出現 |

### 標誌性動效（全部限制在這幾個，不要再加）

1. **絲線進度：** HUD 的進度環改成一條金色細線沿圓周「被織出來」（`stroke-dashoffset` 動畫），完成時線的端點收攏成一個點，然後淡出。
2. **譯文浮現：** 每段譯文出現時，透明度 0 → 1，同時上移 2px，時長 180ms。同一批次內每段延遲 30ms，最多延遲 10 段（之後不再增加延遲）。只用 `opacity` 和 `transform`。
3. **劃詞卡片：** 從選區方向出現：縮放 0.96 → 1，透明度 0 → 1，時長 200ms。流式譯文的光標是一小段金色絲線在閃，不用方塊光標。
4. **加載中：** 一條金色細線從左往右掃過（1.2 秒一個循環），不用轉圈。

### 必須遵守

- `@media (prefers-reduced-motion: reduce)` 下關閉所有位移和縮放，只保留不超過 120ms 的淡入淡出，加載動畫改為靜態。
- 雙語譯文的浮現動畫必須能在設置裡關閉，有些用戶覺得頁面在動會分心。

## 7. 組件規範

### 7.1 工具欄面板（popup）

- 寬度保持 372px。背景 `--bg`（紙色），內容放在 `--card` 白卡片裡，卡片之間 10px。
- 頂部品牌區：圖標 28px + 「絲譯」標題 + `Beta` 徽章（`--accent-soft` 底、`--accent` 字）。
- 主按鈕「翻譯此頁」：
  - 整寬，高 40px，`--accent` 底，`--radius`
  - 按下時縮放 0.98
  - 翻譯中，按鈕底部有一條 2px 的金色絲線進度條
- 分段控件（模式、樣式）：`--field` 底；選中項為白色卡片，帶 1px `--line` 和極輕陰影。
- 額度：一條細進度條（高 4px）。用量 < 80% 時用 `--accent`，≥ 80% 時用 `--warn`，100% 時用 `--danger`，旁邊附文字說明。

### 7.2 頁面懸浮條（HUD）

- 保持膠囊形、右下角、毛玻璃。左側圓形徽章改為：白底或深色底，上面是**金色絲線進度環**（見第 6 節）。
- 空閒自動收起後，只保留 32px 的圓形徽章。
- 必須在白底、黑底、彩色背景的網站上都看得清：邊框 1px `--line`，加陰影。

### 7.3 劃詞卡片

- 最大寬度 360px，`--radius`，毛玻璃。
- 原文一行（`--muted`，caption 字號，超長省略），下方是譯文（card-text 字號）。
- 底部操作：複製、朗讀、切換方向。用圖標按鈕，懸停時顯示提示文字。
- 原文和譯文之間用一條**金色細絲線**分隔（1px，寬度 24px，左對齊）。這是唯一的裝飾。

### 7.4 雙語譯文（寫進網頁裡）

- **繼承頁面的字體、字號、顏色**。不設背景色，不改字重。
- 可選樣式（`src/shared/settings.ts` 的 `BilingualStyle`，現為 `'dashed' | 'highlight'`），新增 `silk` 並設為新安裝的默認值：
  - `silk`（新增）：譯文下方 1px 的 `--silk` 色點狀下劃線，`text-underline-offset: .32em`。
  - `dashed`（現有的虛線下劃線）：保留。
  - `highlight`：底色改為 `--silk-soft`，不再用其他顏色。
  - 已安裝用戶保留他們原來的選擇，不要強制遷移。
- 因為譯文寫在別人的頁面裡，不在 Shadow DOM 裡，顏色值要寫在內聯樣式中（沿用現有 `innerStyle()` 的做法），並通過 `color-mix` 適應頁面的深淺。

## 8. 圖標

由 `scripts/gen-icons.mjs` 程序生成（零依賴，保持這個做法）。

- **造型：** 圓角方形，墨色靛藍底（`#2F4C9A` 到 `#1F3570` 的輕微對角漸變）。
  - 上方：一條白色短橫線，代表原文。
  - 下方：一條金色（`#E0BC7A`）絲線，從右上方的白線末端彎下來，然後水平延伸，代表譯文。
- **商店規格：** 128×128 PNG，實際圖形 96×96，四周各留 16px 透明邊距。
- **小尺寸：** 16px 和 32px 時去掉漸變，絲線加粗到至少 2 個像素寬，保證能看清。
- 在淺色和深色的瀏覽器工具欄上都要檢查。

---

## 9. 文案語氣

- 短、直接、不賣萌，不用感嘆號。
- 錯誤信息說清楚「發生了什麼」和「可以怎麼做」，例如：「今日額度已用完，明天 08:00 重置」。
- 繁中界面用台灣用語（影片、軟體、網路、設定），香港用戶後續可加 `zh-HK` 文案變體。

## 提示詞正文

請為一個 Chrome 瀏覽器擴展設計 Chrome 應用商店的宣傳物料：宣傳圖、商店截圖和一段宣傳動畫。所有畫面使用同一套視覺系統，文字圖層可編輯。

### 產品

- 名稱：絲譯（英文 Silk Translate）
- 一句話：為繁體中文用戶和開發者打造的 AI 網頁翻譯——快、用詞道地、不亂翻代碼。
- 核心功能：
  1. 整頁雙語對照：譯文出現在原文段落下方
  2. 覆蓋原文：直接替換成譯文，鏈接、粗體、行內代碼等格式保持不變
  3. 劃詞翻譯：選中文字後彈出譯文卡片，可複製、朗讀
  4. 開發者友好：代碼、命令、API 名稱不翻譯；技術術語可以保留英文或「中文（English）」並列
  5. 繁中在地化：用台灣慣用詞（影片、軟體、網路、程式），不是簡中轉字形
- 目標用戶：台灣、香港的繁中用戶；讀英文技術文檔的開發者。

### 視覺系統：「Silk & Ink（絲與墨）」

理念：譯文像一縷絲線，把原文和譯文輕輕縫在一起，不撕裂原來的頁面。安靜、精準、東方而現代。**不要**書法字、水墨畫、祥雲、燈籠、龍這類符號，東方感只靠配色和一條絲線表達。

顏色：

- 墨靛藍 `#2F4C9A`（主色），深墨 `#1F3570`，文字墨色 `#1B2230`
- 紙白 `#F6F3EC`（暖白背景），卡片白 `#FFFFFF`
- 絲線金 `#E0BC7A`（深色底上）/ `#A87A32`（淺色底上）。用於絲線圖形和強調細節，不用於大段文字
- 朱砂 `#C2412D`：只用在品牌標誌的小印章元素上，整個畫面最多一處
- 深色場景背景 `#121620`

字體：

- 中文標題：思源宋體 / Noto Serif TC，字重 SemiBold
- 中文正文和界面：思源黑體 / Noto Sans TC
- 英文：Inter
- 代碼：JetBrains Mono

核心圖形：**一條細而流暢的金色絲線**。它從原文的一行文字末端彎下來，延伸成譯文的那一行。在不同畫面裡反覆出現：連接原文和譯文、作為進度線、作為分隔線。線寬 2–3px，曲線平滑，像真的絲線在光下的微微高光。

標誌：圓角方形，靛藍底（`#2F4C9A` 到 `#1F3570` 的輕微對角漸變）。上方是一條白色短橫線（原文），下方是一條金色絲線，從白線末端彎下來再水平延伸（譯文）。右下角可以有一個很小的朱砂方印。

### 交付物 1：小宣傳圖 440×280（必需）

- 商店官方建議：盡量不放文字；縮小到一半時仍然清楚；用飽和的顏色；畫面填滿、邊緣清晰；避免大面積白色或淺灰（商店頁面本身是淺灰底）。
- 構圖：整幅墨靛藍背景。中間是放大的標誌圖形：上方幾條白色的「原文行」（抽象的圓角橫條，不是真實文字），一條金色絲線從第一行末端流下來，織成下方幾條金色和淡白色的「譯文行」。
- 不放文字；如果需要，只在角落放「絲譯」兩個字的小標誌。

### 交付物 2：大宣傳圖 1400×560（可選，用於商店推薦位）

- 左側 40%：標誌 + 「絲譯」大字（Noto Serif TC）+ 一行標語「網頁翻譯，如絲無痕」+ 英文小字「Silk Translate」。
- 右側 60%：一個簡化的瀏覽器窗口，裡面是一個**虛構的**技術文檔網站「Lumen Docs」。英文段落下方是繁中譯文，一條金色絲線從右側流過，把幾段原文和譯文串起來。
- 背景：墨靛藍到深墨的漸變，右側窗口是淺色界面，形成對比。

### 交付物 3：商店截圖 × 5，每張 1280×800

規格：直角、滿版、不留白邊。商店會把截圖縮小到 640×400 顯示，所以每張只講一件事，標題要大，界面細節不要太小。

統一版式：

- 頂部 25%：紙白背景，一行標題（Noto Serif TC，56px 左右，墨色）+ 一行副標題（Noto Sans TC，24px，灰色）。
- 下方 75%：一個瀏覽器窗口的真實界面截圖或高保真還原，略微下沉到底邊。
- 每張都可以有一條金色絲線作為視覺引導，從標題流向畫面的重點。

各張內容：

1. **整頁雙語對照**
   - 標題「一鍵雙語，原文譯文對照讀」，副標題「譯文就在原文下方，排版不亂」
   - 畫面：虛構英文技術博客「Northwind Engineering」，每段下方是繁中譯文，譯文帶金色點狀下劃線；右下角是擴展的懸浮控制條（膠囊形、毛玻璃、金色進度環）。
2. **覆蓋原文，格式不變**
   - 標題「直接翻成中文，連結和格式都在」，副標題「粗體、連結、行內程式碼原樣保留」
   - 畫面：同一類頁面切換到覆蓋模式，中文段落裡的連結（靛藍）、粗體、`npm install` 這樣的行內代碼都保持樣式。
3. **劃詞翻譯**
   - 標題「選一段，馬上懂」，副標題「流式譯文，可複製、可朗讀」
   - 畫面：英文新聞頁裡一段文字被選中（淺靛藍選區），旁邊彈出半透明卡片：上方一行灰色原文，一條短金色絲線分隔，下方是繁中譯文，底部是複製、朗讀圖標。
4. **為開發者設計**
   - 標題「程式碼不亂翻，術語由你決定」，副標題「API、命令原樣保留，術語可中英並列」
   - 畫面：虛構文檔「Lumen Docs」的 API 頁面。代碼塊完全不變；正文裡是「回傳一個非同步結果（Promise）」這類中英並列的效果；右上角一個小浮層顯示術語選項：翻譯 / 保留英文 / 中英並列。
5. **道地繁中**
   - 標題「台灣用語，不是簡轉繁」，副標題「影片、軟體、網路，讀起來就是自己人寫的」
   - 畫面：左右兩張卡片對比同一句英文的兩種譯文。左邊標「一般機器翻譯」（灰色，用詞是「視頻、軟件、網絡」，這些詞用淡紅色波浪線標出）；右邊標「絲譯」（白色卡片，用詞是「影片、軟體、網路」，這些詞用金色下劃線標出）。不要出現任何真實產品或競品的名字。

### 交付物 4：宣傳動畫（約 25 秒，1920×1080，16:9，可上傳 YouTube 作為商店宣傳影片）

節奏：安靜、流暢，沒有閃爍和抖動。緩動曲線類似 `cubic-bezier(0.2, 0.8, 0.2, 1)`。配樂建議：輕柔的鋼琴或撥弦，無人聲。

分鏡：

| 時間 | 畫面 |
|---|---|
| 0–3 秒 | 墨靛藍背景，一條金色絲線從左側緩緩飄入，畫出標誌：白色原文線 → 絲線彎下 → 金色譯文線。「絲譯」字樣淡入。 |
| 3–8 秒 | 鏡頭推入一個瀏覽器窗口，英文技術博客。點擊工具欄圖標（或按 Alt+T），右下角的懸浮條出現，金色進度環開始「織」。 |
| 8–13 秒 | 譯文從上到下逐段浮現在原文下方：每段淡入並上移 2px，段與段之間間隔很短。字幕：「一鍵雙語」。 |
| 13–17 秒 | 切換到覆蓋模式，英文段落平滑變成中文，連結和行內代碼保持樣式。字幕：「格式不亂」。 |
| 17–21 秒 | 鼠標選中一段英文，劃詞卡片從選區處展開，譯文流式出現，光標是一小段閃動的金色絲線。字幕：「劃詞即譯」。 |
| 21–25 秒 | 絲線從畫面中收攏，回到標誌。標語「網頁翻譯，如絲無痕」+「Chrome 應用商店免費安裝」。 |

另外請做一個 **6 秒的無縫循環版**（1080×1080），只保留絲線織出標誌，以及一段英文變成雙語的畫面，用於社交媒體。

### 規則

- 所有網站都用虛構名稱（Lumen Docs、Northwind Engineering 等），不要出現任何真實網站、公司的 logo 或名稱，也不要出現 Google 或 Chrome 的標誌。
- 不要出現任何 AI 模型或競品的名字。
- 界面元素要和我附上的真實截圖一致：工具欄面板寬 372px，懸浮條是右下角的膠囊形，劃詞卡片是半透明圓角卡片。不要發明產品沒有的功能。
- 文字主語言：繁體中文（台灣用語）。完成後，請再為小宣傳圖、大宣傳圖和截圖 1–4 各出一個英文版和一個簡體中文版，版式不變，只換文字。
- 每張圖都要在縮小到 50% 時檢查：標題能讀清，重點一眼能看到。

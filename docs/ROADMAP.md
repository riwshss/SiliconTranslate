> **給 Claude Code：** 開始任何功能開發前先讀這份文件。
> - 「開發原則」（第 3 節）是硬約束，和任務描述衝突時先停下來問。

> - 完成一項就把 `[ ]` 改成 `[x]`，並在第 8 節「決策記錄」追加一行（日期 + 做了什麼決定 + 原因）。

基線：`main` @ `d2046c3`（v2.2.1 Beta）。118 個單元測試通過，`tsc` 無錯誤；E2E 有一項已知失敗（`host label`）。

## 1. 產品定位

**一句話：** 為繁體中文用戶和開發者打造的 AI 網頁翻譯——快、便宜、用詞道地、不亂翻代碼。

### 目標用戶

| 優先級 | 用戶群 | 他們最在意什麼 |
|---|---|---|
| 主 | 台灣、香港的繁中用戶 | 譯文用詞是當地習慣（「影片」不是「視頻」、「軟體」不是「軟件」），而不是簡中轉字形 |
| 主 | 開發者（不分地區） | 看英文文檔、GitHub、Stack Overflow 時，代碼、命令、API 名稱、技術術語不被亂翻 |
| 次 | 語言學習者 | 讀懂外文而不只是看譯文：結合上下文的詞義、生詞本（Phase 4） |

> **待決定：** 主要市場是台灣、香港、大陸還是海外華人？會影響默認目標語言、定價貨幣和支付方式。

### 差異化（只在這三點上投入，比對手明顯更好）

1. **繁中在地化質量：** 分開台灣、香港兩種用語，界面也有繁體。
2. **開發者友好：** 術語保留策略、技術網站專門適配、行內代碼零破壞（現有標記序列化已經是基礎）。
3. **快而便宜：** 首屏第一段譯文盡快出現；共享緩存讓熱門頁面接近秒開；價格低於主要競品。

### 明確不做（至少到 Phase 4 結束前）

- 視頻字幕翻譯：各平台播放器常改版，維護成本高，競品已很成熟。
- 圖片、漫畫翻譯：需要視覺模型，成本結構完全不同。
- AI 摘要、網頁問答、側邊欄聊天：和翻譯關係不大，會大幅增加 token 消耗，市場已很擁擠。
- 廣告、出售數據：違反商店政策，毀掉信任。

## 2. 架構現狀（速查）

- 擴展：TypeScript + esbuild，MV3，無框架、無運行時依賴。
- 後端：Cloudflare Worker（`server/`）+ Durable Objects 做額度計數。
- 模型：經 OpenRouter 調用；測試期只放行 `deepseek/deepseek-v4-flash`。
- 關鍵文件：
  - `server/src/app.ts`：路由、校驗、額度、轉發 OpenRouter
  - `src/core/prompt.ts`：提示詞
  - `src/background/translator.ts`：批量翻譯、緩存、重試
  - `src/background/api.ts`：HTTP、SSE、退避重試
  - `src/background/account.ts`：安裝 ID、套餐
  - `src/core/batching.ts`、`src/content/batcher.ts`：拆批
  - `src/core/markup.ts`：行內標記序列化與還原
  - `src/shared/languages.ts`：目標語言表
  - `src/shared/i18n.ts`：界面文案

## 3. 開發原則（硬約束）

1. **提示詞只在後端。** Phase 0 完成後，客戶端只發「原文 + 目標語言 + 少量上下文」，絕不發系統提示詞或任意消息。
2. **額度只按原文字數計。** 系統提示詞、上下文、術語表都不計入用戶額度。
3. **新功能不能讓每頁 token 成本成倍增加。** 如果一個功能要額外調用模型，必須是用戶主動觸發（點擊），不能默認對整頁執行。
4. **保持零運行時依賴。** IndexedDB、HMAC 等都用瀏覽器 / Workers 原生 API 自己寫小封裝。
5. **權限最小化。** 不新增必需權限；新能力優先用可選權限或 `activeTab`。
6. **每個改動帶測試。** 純邏輯放 `src/core/` 並寫 Vitest；涉及 DOM 的加 `tests/dom.test.ts` 或 E2E。改完跑 `npm run typecheck && npm test`。
7. **i18n 同步。** 新增界面文案時，所有界面語言（簡中、英文，Phase 1 後加繁中）必須同時補齊。
8. **後端改動向後兼容。** 線上有舊版擴展。改接口時保留舊接口一個過渡期（默認 14 天），並在第 8 節記錄下線日期。
9. **隱私。** 不記錄原文和譯文的明文日誌；指標只存聚合數據。新增的數據收集要同步更新隱私政策。

## 4. 路線圖

### Phase 0：安全與成本地基（上架前必須完成）

目標：後端不能被當成免費 LLM API；重試不放大故障；成本可預測。

- [ ] **0.1 新增專用翻譯接口 `POST /v1/translate`**（`server/src/app.ts`）
  - 請求體：`{ model?, target, title?, kind: 'page' | 'selection', texts: string[] }`
  - 校驗：
    - `target` 必須在 `LANGUAGES` 裡
    - `page`：1–12 段，每段 ≤ 2000 字，總計 ≤ `MAX_REQUEST_CHARS`
    - `selection`：恰好 1 段，≤ 5000 字
  - 後端用 `src/core/prompt.ts` 拼消息（相對路徑 import，由 wrangler 打包）。
  - 額度 = 原文總字數；刪除 `MIN_CHARGE_CHARS`。
  - 驗收：用任意自定義 system 消息調用新接口，必須被拒絕；`tests/server.test.ts` 有對應用例。
- [ ] **0.2 舊接口過渡：** `/v1/chat/completions` 改為單獨的低額度（默認每天 20 萬字/安裝），14 天後返回 `410`。
- [ ] **0.3 客戶端改用 `/v1/translate`**（`src/background/api.ts`、`translator.ts`）
- [ ] **0.4 服務器簽發安裝令牌**
  - 新增 `POST /v1/install`：返回 `id.base64url(HMAC-SHA256(INSTALL_SECRET, id))`。
  - 每個 IP 每天最多簽發 3 個，計數鍵 `issue:${ip}`，用現有 `QuotaStore`。
  - 每個請求用 `crypto.subtle` 驗簽，不訪問 DO。
  - 客戶端：`account.ts` 的 `getInstallId()` 改為 `getInstallToken()`。
  - 過渡期內舊 UUID 只給低額度。
  - 驗收：隨機偽造的 UUID 或令牌被拒（401）。
- [ ] **0.5 修重試放大**
  - `api.ts`：只有 `quota_exceeded`、`upgrade_required`、`model_locked`、`unauthorized`、`bad_request` 這幾種 `X-Silk-Error` 視為最終錯誤；`upstream_error`、`server_error` 要允許重試。
  - `translator.ts`：整個請求失敗時，未完成的段落作為一組重試一次；只有「請求成功但個別段落缺失」時才逐段重試。
  - 驗收：mock 後端連續返回 502 時，一個 12 段的批次發出的請求總數 ≤ 8。
- [ ] **0.6 降低測試版額度**（`server/wrangler.toml`）：`INSTALL_DAILY_CHARS` 降到正式版免費檔水平（**待決定**，建議 5–10 萬字/天）。
- [ ] **0.7 提示詞緩存友好化**（`src/core/prompt.ts`）
  - 系統提示詞改成不含任何變量的常量。
  - 目標語言、頁面標題移到 user 消息開頭。
  - 驗收：用回歸集（見 1.6）對比，質量不下降。
- [ ] **0.8 商店描述修正**：`static/manifest.json` 和 `package.json` 的 description 去掉測試期不可用的模型名。
- [ ] **0.9 CI**：新建 `.github/workflows/ci.yml`。
  - 每次 push 和 PR：`npm ci`、`npm run typecheck`、`npm test`。
  - 打 `server-v*` 標籤時：`wrangler deploy`（`CLOUDFLARE_API_TOKEN` 放在 Secrets）。
- [ ] **0.10 修 E2E `host label`**：疑似因為沒有 `tabs` 權限時 `tab.url` 為空。先確認原因；如果屬實，改測試期望值，不要為此加權限。

### Phase 1：上架 MVP（繁中在地化 + 速度）

目標：在 Chrome 應用商店和 Edge 擴展商店上架，繁中用戶一用就能感覺到「用詞對」。

- [ ] **1.1 目標語言拆分**（`src/shared/languages.ts`）
  - `zh-TW` 的 prompt 名稱強化為台灣用語。
  - 新增 `zh-HK`（香港用語、香港書面語）。
  - 提示詞裡加一段簡短的用語指引，**放在後端、不計額度**。
  - 驗收：回歸集裡的常見詞（影片、軟體、程式、資料、網路、品質）在 `zh-TW` 輸出中正確。
- [ ] **1.2 界面加繁體中文**（`src/shared/i18n.ts`）
  - `UI_LANG_SETTINGS` 加 `zh-TW`。
  - `resolveUiLang` 把 `zh-TW`、`zh-HK`、`zh-Hant*` 都映射到繁中界面。
  - 文案用台灣用語人工校對，不要機器轉字形。
- [ ] **1.3 首屏優先**（`src/core/batching.ts`、`src/content/batcher.ts`）
  - 可見段落的第一批 ≤ 3 段或 300 字。
  - `MIN_BATCH_CHARS` 降到約 150（0.1 和 0.7 完成後，系統提示詞已不計額度、又能命中緩存）。
- [ ] **1.4 客戶端持久緩存**（`src/background/translator.ts`）
  - 在內存 LRU 後加一層 IndexedDB，記錄時間戳；超過 5 萬條時刪除最舊的。
- [ ] **1.5 後端共享緩存**（依賴 0.1）
  - 用 `caches.default`，鍵為 `sha256(model|target|text)`，TTL 7 天。
  - 命中的段落直接返回，額度只扣未命中的部分。
- [ ] **1.6 質量回歸集**（`tests/fixtures/regression/`）
  - 50–100 個真實段落：含行內標記、技術術語、繁中用語陷阱、長句。
  - 加一個腳本，調用真實後端並輸出前後對比，供人工檢查（不在 CI 裡跑）。
- [ ] **1.7 指標**（Workers Analytics Engine，綁定名 `METRICS`）
  - 每個請求記錄：模型、服務商、錯誤碼、字數、首 token 耗時、總耗時、緩存命中 token 數。
  - 不記錄任何原文。
- [ ] **1.8 額度扣減提速**（`server/src/app.ts`、`server/src/index.ts`）
  - `global` 拆成 16 個分片。
  - 全站計數用 `ctx.waitUntil` 在響應後扣減，用模塊級的 `globalExhaustedUntil` 熔斷。
- [ ] **1.9 上架材料**（放在 `docs/store/`）
  - 隱私政策：說明發送哪些數據、緩存什麼、保留多久、轉發給哪些模型服務商。
  - 權限用途說明。
  - 商店描述（繁中、簡中、英文）和截圖。
- [ ] **1.10 Edge 擴展商店**：同一份構建，確認在 Edge 上能正常安裝和翻譯。

### Phase 2：開發者模式

目標：成為開發者讀英文技術內容時的首選翻譯插件。

- [ ] **2.1 術語保留策略**（設置項 + 後端提示詞參數）
  - 三種選擇：翻譯 / 保留英文 / 「中文（English）」並列。
  - 作為請求參數 `termStyle` 傳給 `/v1/translate`，提示詞由後端根據參數拼接。
- [ ] **2.2 網站適配層**（新建 `src/content/adapters/`，每個網站一個文件）
  - 先做：GitHub（issue、PR、README）、MDN、Stack Overflow，以及 Docusaurus、VitePress、Read the Docs 等常見文檔框架。
  - 每個適配器聲明：跳過的選擇器（用戶名、時間、按鈕、代碼塊）、優先翻譯的主內容區域、特殊處理。
  - 驗收：每個適配器有 DOM 測試，用保存下來的頁面片段做 fixture。
- [ ] **2.3 按網站的術語表**
  - 用戶可以在面板裡為當前網站添加「原文 → 譯文」，存在 `chrome.storage.sync`。
  - 請求時附帶命中的條目（最多 20 條，不計額度）。
- [ ] **2.4 自動術語一致性**
  - 同一頁面內，從已翻譯批次中提取專有名詞的對照，附帶到後續批次。
  - 做成純函數放在 `src/core/`，並寫單元測試。

### Phase 3：收費版

目標：免費層幾乎零成本，付費層毛利可控。

- [ ] **3.1 賬號體系**：郵箱魔法鏈接登錄（Worker + KV），或者直接用支付平台自帶的登錄（**待決定**，見第 5 節）。額度和套餐掛在賬號上；未登錄的只給很少的額度。
- [ ] **3.2 套餐解析**（`server/src/app.ts`）：常量 `CURRENT_PLAN` 改為 `async resolvePlan(token)`，從 KV（`plan:${accountId}`）查詢，查不到就是 `free`。
- [ ] **3.3 支付接入**：Checkout → Webhook → 寫 KV。支持訂閱和一次性加油包。
- [ ] **3.4 免費層使用 Chrome 內置翻譯**
  - 在內容腳本裡特性檢測 `'Translator' in self`；可用時整頁翻譯走本地。
  - 不提高 `minimum_chrome_version`，不可用時降級為少量 AI 額度。
- [ ] **3.5 隱私模式**：郵箱、網銀、內網類網站（內置名單 + 用戶自定義）強制使用本地翻譯；本地不可用時提示用戶，而不是靜默發到雲端。
- [ ] **3.6 用量界面**：面板顯示本月用量、剩餘額度；用到 80% 時提醒；有升級入口。
- [ ] **3.7 法律頁面**：服務條款、退款政策、取消訂閱說明。
- [ ] **3.8 測試用戶過渡**：早期用戶贈送 1–3 個月 Pro（**待決定**）。

### Phase 4：擴展（視數據決定）

- [ ] **4.1 學習模式**：雙語模式下點擊單詞，顯示結合上下文的釋義（用戶點擊才觸發，符合原則 3）；生詞本；導出到 Anki。
- [ ] **4.2 導出雙語版**：把當前頁面的譯文導出為 Markdown 或 PDF。
- [ ] **4.3 熱門網站適配擴展**：Reddit、X、YouTube 評論、Hacker News、主流新聞網站。
- [ ] **4.4 Firefox**：只在 Chrome 和 Edge 數據理想時再考慮。

## 5. 商業模式

### 套餐（數字均為暫定，**待決定**）

| | 免費 | Pro | 加油包 |
|---|---|---|---|
| 整頁翻譯 | Chrome 內置翻譯（本地，零成本） | AI 翻譯 | — |
| AI 額度 | 每月 5–10 萬字（試用、劃詞） | 每月 1000–2000 萬字 | 一次性 500 萬字 |
| 模型 | DeepSeek V4 Flash | 全部 4 個 | 跟隨套餐 |
| 開發者模式、術語表 | 基礎 | 全部 | — |
| 價格 | 免費 | 約 US$3.99–4.99/月，年付打折 | 約 US$2–3 |

價格錨點：主要競品的 Pro 月費約 ¥69，價格要明顯低於它。

### 成本估算方法

先用下面的公式粗估，**上線後必須用 OpenRouter 的實際賬單校準**。

- DeepSeek V4 Flash：每百萬 token 輸入 $0.091、輸出 $0.182（見 README，以 OpenRouter 當前價格為準）。
- 英文 → 中文時：每 100 萬字原文 ≈ 25 萬輸入 token + 約 50 萬輸出 token ≈ **US$0.12**，另加提示詞開銷。命中前綴緩存後，提示詞部分的成本很小。
- 規則：付費用戶**用滿額度**時，模型成本 ≤ 售價的 30–40%。剩下的留給支付手續費、稅和基礎設施。
- 只要啟用 Claude Haiku 5.5、GPT-6 Sol、Gemini 3.8 Flash，單位成本就會成倍上升。這些模型的額度要單獨按倍率計算，例如用 1 萬字 GPT-6 Sol 扣 N 萬字額度。

### 支付（**待決定**）

| 方案 | 優點 | 缺點 |
|---|---|---|
| ExtensionPay | 最快接入，自帶登錄 | 抽成約 5%，不代繳稅 |
| Merchant of Record（Paddle、Dodo 等） | 代處理各國增值稅和銷售稅 | 抽成較高，有審核 |
| 自建 Stripe + Worker + KV | 費率最低，完全可控 | 自己處理稅務和賬號 |

如果主要市場包含中國大陸，還要確認支付寶、微信支付的支持情況。
